规范注解图例（编号对应预览中的黄色标记）

  1. 条件条 chip 角色误用：可移除的已选项在 M3 中属 FilterChip（selected 语义 + ✓ 前导 + secondaryContainer 容器）；AssistChip 语义是「点击触发一个动作」。且无 ✕ 视觉提示，用户无从知道「点 chip = 移除该条件」。
  2. 条件条装卸无过渡：if (filter.isNotEmpty()) 直接装/卸，清掉最后一个条件时整条瞬闪；建议 AnimatedVisibility + motionScheme。
  3. 视频卡：16:9 封面 / 已观看徽标 / 播放量+时长 scrim / 两行强调标题（AppEmphasis.cardTitle）/ surfaceContainerLow 容器 / 20dp 圆角——与 M3 卡片规范一致，无需改动。
  4. 空态无恢复动作：M3 empty state 规范 = 插画 + 标题 + 说明 + 动作按钮；建议补「重置筛选 / 重试」。
  5. Sheet 首屏信息序：历史组合 + 预设先于 6 个核心筛选维度，进 sheet 的第一诉求（改筛选）被挤到首屏外。
  6. 维度块（AdvancedSearchChip）三连问题：① selected 仅换色、无 ✓（M3E：状态不得仅靠颜色传达）；② 长按清除只有底部一行 tips 提示，可发现性弱；③ tips 文案中英混排未本地化；④ 两列时值（如「2026年3月」）必截断。
  7. 单选列表两处规格问题：① 未选项容器色 = card = surfaceContainerHigh，与对话框底同色，行边界不可见；② 单选用了 check_circle 图标（多选视觉语言），M3 单选应为 RadioButton。
  8. 多选标签 = 复杂任务：7 tab + 搜索 + 200+ 选项 + 开关塞在 AlertDialog 里，超出 dialog 的轻量定位；M3 指南建议改全屏对话框（full-screen dialog）。
  9. 年月滚轮打开即停在 1990：LazyColumn 无初始滚动位置，当前选中值（默认今年）在 37 项之外不可见；且无居中高亮带 / 无滚动吸附。
  10. 宽屏常驻栏：与底栏弹窗同一 FilterBlockSpec 复用、主操作钉底、240dp 单列避免长值截断——响应式处理正确，保持。

发现页 UI 设计评价与改进意见

一、总体评价

发现页（SearchScreen + 筛选器家族）是这套项目里设计系统执行力最强的页面之一：色板全部由 materialkolor 从种子色现场算（三端同源）、间距/圆角/字阶全部 token 化、筛选器做到了「6 维度 + 预设 + 历史 + 模糊配对」的完整闭环，且窄屏（ModalBottomSheet）与宽屏（240dp 常驻栏）双形态共用同一份 FilterBlockSpec。问题集中在官方组件语义的替换（AssistChip/FilterChip、自绘 chip、单选图标）与若干规格偏离（自绘搜索栏 80dp vs 官方 56dp、滚轮打开位置、空态动作缺失），多数可在不动信息架构的前提下修复。

二、做得好的地方（保持）

  • token 纪律：间距唯一真源 HanimeDefaults.Spacing（4/8/12/16/24/32）、圆角显式阶梯 AppShapes（4/8/12/16/20/28/32/48）、强调字阶 15 档全量 Bold 并收敛到 AppEmphasis 语义层——业务层不直写 typography。
  • tonal 优先：筛选选中态统一 secondaryContainer/onSecondaryContainer tonal 配对，不用 alpha 叠加；搜索栏从「双 Surface 叠 tint」收敛为单容器（注释记录了理由）。
  • 动效走 motionScheme：历史列表进出场、chip 颜色切换、按压形变插值（shapeByInteraction）全部走 fastEffectsSpec/fastSpatialSpec，无硬编码 tween。
  • 对比度实测全部过 AA：见下方色值表（最低 6.50:1，outline 4.27:1 属非文本 3:1 档，通过）。
  • 无障碍基本盘：SelectableTag 用官方 FilterChip（自带 Role.Checkbox + ✓ 前导），替代了此前的自绘 Box+clickable；全项目 haptic 反馈统一收口。
  • 状态完备：骨架屏 + 趣味加载文案 / 空态 / 错误态（带原因）/ 下拉刷新 / 分页 footer（M3E LoadingIndicator）都有专门实现。
  • M3E 组件选型正确处：PrimaryScrollableTabRow 分类页、SingleChoiceSegmentedButtonRow 日期模式切换（P1 #10：旧版两个同貌按钮无选中反馈，已修）、Switch + 两行说明、ShortNavigationBar/WideNavigationRail。
  • 工程质量细节：发布日期 chip 曾误绑 onClearDuration（点「发行日期」连带清掉「时长」）——这类修复都留在注释里，可追溯。

三、改进意见（按优先级；依据 = M3/M3E 规范或锁定版字节码核验值）

P01. 已选条件条：AssistChip → FilterChip（selected + trailing ✕）

问题：点 chip = 移除该条件，但 AssistChip 无 ✕ 提示、无 selected 语义，TalkBack 读不出「已选中/可清除」。依据：M3 chip 家族分工——AssistChip = 点击触发动作；FilterChip = 选中/取消选中（selected 容器即 secondaryContainer，与现配色一致）。改法：FilterChip(selected=true, onClick=onClearX, label=…, trailingIcon={Icon(close)})，切换零视觉回归；「重置」保留 AssistChip（它确实是动作）。

P02. 高级筛选维度块：补 ✓ 前导（或改 FilterChip / ListItem 规格）

问题：AdvancedSearchChip 选中仅换容器色，无任何勾选标记；色觉障碍 / 高对比度用户不可辨。依据：M3 FilterChip selected 必有 ✓ leading icon；M3E 规范「状态不得仅靠颜色传达」。改法：选中时补 18dp ✓ 前导；或按 M3 两行 ListItem 规格（72dp：headline=维度名 / supporting=值 / trailing=✕）重构，天然获得官方形态与触控目标。

P03. 顶栏搜索栏自绘且超规格：≈80dp vs 官方 SearchBar 56dp

问题：实测高度 = 8(容器)+4(行)+56(56dp 漏斗钮)+4+8 ≈ 80dp，比 M3E SearchBar（SearchBarTokens.ContainerHeight = 56dp，字节码核验）高 43%；且缺 leading 放大镜图标（M3 SearchBar 强制 leading icon）、clear 按钮在输入框外。改法：首选迁移 M3E SearchBar/DockedSearchBar（自带 56dp、full 圆角、展开动画与 suggestions 槽）；保留自绘则至少补 leading icon、clear 内移、高度压到 56dp。

P14. Sheet 首屏信息序：核心筛选维度被历史/预设挤到首屏外

依据：M3 bottom sheet 内容应「任务优先」+ 渐进披露。改法：6 个维度块上移并加区标题（「筛选条件」）；历史组合收成一行入口（「最近使用 ▾」）或移到结果页条件条附近；预设保留一行横滑。

P15. 维度顺序两处不一致

结果条件条序（类型/标签/排序/日期/时长/品牌/模糊）≠ Sheet blocks 序（类型/排序/标签/品牌/日期/时长）。同一组信息两种序列，用户每次重新扫描。统一为同一顺序（建议按站点字段序或使用频率）。

P16. 多选标签对话框改全屏对话框（full-screen dialog）

依据：M3 对话框指南——简短确认用 AlertDialog，复杂任务（长列表 + 多步操作）用全屏对话框（头部标题 + 全高内容 + 底部动作）。当前 7 tab + 分类搜索 + 200+ 选项 + 开关塞在 312dp 宽的 dialog 里，pager 可视区仅 ~320dp 高。

P17. 单选列表：图标与容器两处规格问题

问题：① 未选项容器 = HanimeDefaults.Colors.card = surfaceContainerHigh，与 AlertDialog 底（DialogTokens.ContainerColor = SurfaceContainerHigh，字节码核验）同色，行边界完全不可见；② 单选用 check_circle（多选视觉语言）。改法：未选项给 surfaceContainerLowest 或 1dp outlineVariant 边框；单选改 M3 RadioButton。

P18. 年月滚轮：打开停在 1990 + 无吸附/居中高亮

问题：WheelLikeColumn 的 LazyColumn 无初始滚动位置，弹窗打开时列表在首项（1990），当前选中值（默认今年 2026）在 37 项之外，用户看不到当前值；也没有 wheel 惯用的「选中行居中 + 上下渐隐 + 点击居中」。改法：rememberLazyListState(initialFirstVisibleItemIndex = indexOf(selected)) + 居中高亮带 + snapToItem 吸附；或年份加「最近 5 年」快捷跳转。

P19. 空态 / 错误态补恢复动作

依据：M3 empty state 规范 = 插画 + 标题 + 说明 + 动作按钮。改法：空态给「重置筛选」/「修改关键词」TextButton，错误态给「重试」——都走已有的 HapticTextButton。

P110. 长按清除的可发现性

项目自己在预设区注释里承认「同一块界面再叠一层长按语义会让用户不敢点」，但维度块仍用长按清除，仅靠底部 tips 一行小字告知。建议选中态直接露出 ✕（与第 2 条一并解决），长按退为快捷方式；tips 同步改为中文。

P211. 文案本地化与准确性

① search_options_tips 中英混排（「Tips:长按某单元…所有tag」）→「提示：长按某个维度可清除该维度已选的全部标签」；② switch_to_year「切换至年」→「仅按年筛选」；③ 未选时值显示「全部」，但服务端空参可能有默认排序——建议显示「站点默认」或具体默认值名（需与 wire 行为核对）；④ 历史卡条件串「 · 」连接 2 行截断，建议 chips 化或点击展开。

P212. 动效与细节打磨

① 条件条进出无过渡（见注解 2）；② ModalBottomSheet 禁用 HalfExpanded，内容多时无法「半展开瞄一眼」，建议放开；③ Sheet 内层再包 Surface（默认 surface 色）属冗余一层——与搜索栏刚修掉的「双 Surface 叠 tint」同型，建议直接给 ModalBottomSheet 内容上色；④ dialog 内「重置」与「取消」同槽相邻，重置是即时生效的破坏性操作，建议移出或加 error 色/二次确认。

P213. 两列维度块的值截断

390dp 屏两列时块宽 ≈150dp，「发布日期: 2026 年 3 月」必截断（组件注释已承认）。改法：值允许 2 行（minLines=2 + maxLines=2）保信息完整，或窄屏改单列（块高 +60dp，但一屏可见维度减少，需权衡）。
