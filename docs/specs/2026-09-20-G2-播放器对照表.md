# G2-3a 播放器对照表（animeko × 本仓）

> 结论先行：animeko **也没有**画面调节 UI、字幕/音频偏移滑杆、PiP 入口、独立清晰度按钮——
> 它的 mpv 侧能力只透过桌面端 mpv 透传文本实现。所以 G2-3b/c/d 里"对齐 animeko"只覆盖到透传对等；
> 字幕 UI、音频偏移 UI、画面调节 UI 是**本仓自有需求**（Hanime 场景），按自有标准做。
> 未逐项验证的标"待确认"，不写死。

## 落到 G2-3b/c/d/e

* **G2-3b 画面调节+画面比例**：mpv `brightness/contrast/saturation`（桌面+安卓 mpv），Exo/iOS 无原生对等项如实标注、不做假开关（Gate 4 无占位）；画面比例 FIT/STRETCH/CROP 三端做（mpv `video-aspect-override` / Exo scalingMode / iOS `videoGravity`，`PlatformVideoSurface.ios` 已有等比基础）。
* **G2-3c 字幕 / G2-3d 音频偏移**：不做（2026-09-20 决策）。
* **G2-3e 清晰度体验**：不断播切换 + 偏好记忆，打磨项。
* **不做（首版）**：字幕、音频偏移、音轨选择、帧预览/统计叠层；锁屏手势、OP/ED 跳过进候选，不 blocking。
* **待确认三项**（倍速记忆/错误自动换源/自动连播）：实现前先 grep 定性，已有则从清单划掉，不重复造。
