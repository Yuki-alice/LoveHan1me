# LoveHan1me 项目重新定位梳理

> 日期：2026-09-20 ｜ 状态：已定稿（本文档取代此前所有归档规划，是当前唯一有效的项目级规划）
> 产出方式：代码事实盘点 + 逐项问答收敛，旧文档体系（P/M 阶段编号）全部作废。

## 1. 定位

**LoveHan1me：独立演进的三平台（Android / Desktop / iOS）开源番剧播放器，双站点（Hanime1 + Getchu），体验标杆 animeko，从 Han1me 起家、半独立偶尔同步上游。**

关键身份转变：不再是"Hanime 的多平台 fork"，而是自己的项目，上游只是原料来源之一。

| 维度 | 结论 |
|---|---|
| 发布形态 | GitHub 开仓 + Release（APK / 桌面安装包 / iOS 源码+侧载说明） |
| 发布标准 | 三平台功能齐整、无 no-op 占位、体验对齐 animeko 才发第一版 |
| 上游关系 | 半独立，每月一次 cherry-pick 窗口，解析修复优先，UI 不动 |
| 平台优先级 | 三平台同等重要 |
| 站点策略 | 现有两站，不主动扩；竞争力来自对现有站点的覆盖纵深 |
| 投入模式 | 单人 + AI，稳定投入 |

## 2. 边界（Non-goals）

- 不扩第三站，不做站点插件化/社区扩展体系
- iOS 不追付费分发（无开发者账号）：Release 形态 = 源码 + Xcode 工程 + 自签侧载文档
- 不跟随上游大版本节奏

## 3. 现状盘点（代码事实）

**已具备的能力：**
- KMP 迁移基本完成：UI/业务全在 `:shared` commonMain（414 文件），`:app` 已是薄壳（28 文件，含 1 个 instrumentedTest，主代码 27）
- 多站点抽象 + 热切换（SiteIdentity / SiteSwitcher，最新提交刚补齐 javchu 切换边缘）
- 播放器三引擎（Android Exo / DesktopMpv / IosAVPlayback），animeko 式控件复刻中
- 双源弹幕（评论主源 + 弹弹增强：CommentDanmakuMapper + DandanplayApi）
- Room KMP / DataStore / Navigation 3 / commonTest（17 文件）/ build-logic 约定插件
- CI 双流水线：Windows（Android+Desktop 构建 + desktopTest）+ macOS（iOS 编译）
- 开源合规工具链：LICENSE / NOTICE / license_similarity_scan / find_orphan_strings

**架构债（Gate 1 素材）：**
- `:app` 剩 28 文件待归位（入口类保留，逻辑类下沉 `:shared/androidMain`，现有 55 文件）
- compileSdk 双版本（`:shared`=36 / `:app`=37，CI 需装双平台；收敛到单版本需同步降 targetSdk，属行为变更另立议题，见 gradle.properties 注释）
- 全仓 33 处 `TODO P5/P7`、`M6 契约` 等死编号引用
- 脚手架残留：P3aVerificationScreen、CookieSmoke、IsDebugBuild 假实现
- 站点热切换、双源弹幕刚落地，边缘补丁痕迹未收

**平台能力占位（Gate 3 素材，占位型 no-op，不含平台本无语义的 by-design no-op）：**
- iOS：触感反馈、相册写入、ImageLoader 特化、下载收尾（IosDownloadWorkController 已有骨架，VideoCacheStore 仍 no-op）
- Desktop：下载收尾（DesktopDownloadWorkController 已有真实现，PlatformStores 注释 stale 待更新）、调试构建对话框

**体验风险（Gate 3 素材）：**
- 播放器历史两次 revert（白屏/闪烁/每帧重建：468092b、f9d2cad、f4c2e4a），稳定性需回归测试护航
- 性能 live test（WatchFetchPerfLiveTest 等）随 desktopTest 默认跑、需联网易抖，尚无 CI 门槛/隔离策略

## 4. 路线图：四道 Gate

顺序严格不可跳，Gate 内自由排序。每道 Gate 有明确 DoD。

### Gate 1「收口」——让代码库只说一种语言

| 事项 | 代码证据 |
|---|---|
| `:app` 28 文件归位：入口类（MainActivity/Application/Worker/Activity）保留，逻辑类下沉 | settings.gradle.kts L55 注释的既定方向 |
| 统一 compileSdk（已收敛单 37：26 个 AAR 声明 minCompileSdk≥37，单 36 不可行；appTargetSdk 已降 36，待真机实测） | ci.yml 单 37 安装+断言 + gradle.properties 注释 |
| 死编号清理：`TODO P5/P7`、`M6 契约` 改写为 issue 或新任务描述 | 全仓 33 处 |
| 删脚手架：P3aVerificationScreen、CookieSmoke、IsDebugBuild 假实现 | desktopApp |
| 站点热切换 + 双源弹幕边缘收尾 | git log 最新三个 fix |

**DoD**：`:app` 只剩纯入口；CI 不再需要双 SDK 版本特判；全仓 grep 不到 P5/P6/P7/M6 编号；自用一周无站点切换/弹幕 bug。

### Gate 2「功能纵深」——竞争力主战场

| 方向 | 内容 | 备注 |
|---|---|---|
| 源站覆盖补全 | 作者页（列表+详情+关联视频）、comic 子站（浏览+阅读） | 复用 `site/hanime1` 解析体系 |
| CF 攻坚 | 自动过盾（WebView 自动收割 cookie 等方案），手动 cookie 保留为降级路径 | **时间盒 spike**：风险最高，失败不阻塞其他项 |
| 播放器深度 | 补齐 animeko 对照表：画面调节、字幕支持、音频偏移、多清晰度切换体验 | 手势/倍速长按已有 |

**DoD**：作者页/comic 三平台可用；CF 自动过盾有实测成功率数据（或明确失败结论+降级方案）；播放器功能清单对齐 animeko 对照表。

### Gate 3「齐整」——三平台功能对齐

| 事项 | 说明 |
|---|---|
| 平台能力补位 | iOS 触感/相册写入/ImageLoader/下载收尾，桌面下载收尾、调试构建对话框 |
| Gate 2 新功能三平台查漏 | 新功能开发时即三平台同步写，此处只查漏 |
| 播放器稳定性专项 | 白屏/闪烁历史问题建回归测试再继续控件复刻 |
| 性能基线 | live test 加门槛/隔离策略（当前随 desktopTest 默认跑、需联网），列表滑动/搜索响应建基准 |
| 下载链路三平台拉齐 | 桌面/iOS 收尾（引擎骨架已有，VideoCacheStore 仍 no-op；PlatformStores stale 注释同步更新） |

**DoD**：全仓无占位型 no-op（平台本无语义的 by-design no-op 除外，如截屏保护桌面/iOS、DNS+iOS 等，需注释标明）；三平台功能清单逐项打勾；播放器连续自用两周无崩溃/白屏。

### Gate 4「发布」——GitHub 开仓（发布标准维持不变：三平台齐整、无占位、体验对齐 animeko）

- README（定位/截图/三平台构建说明）+ 旧 `docs（不做参考）` 目录处置 + 断链修复（README 引用的 `定位.md` 缺失、iOS“规划中”已过时）
- Release 流水线：tag 触发 → APK（arm64）+ 桌面安装包 + iOS 源码说明，签名、changelog
- 敏感信息终检（local.properties、镜像 URL、cookie 处理路径、AppUpdateChecker 硬编码 update URL）
- 合规终检：NOTICE、aboutlibraries 第三方许可、上游许可声明
- 版本命名定夺（当前 26.3.2 日历式 vs 语义化）
- 仓库卫生：issues 模板 + .gitignore 复查（iosApp/build 产物是否误纳）

**DoD**：陌生人 clone 后按 README 三平台都能构建出可用产物。

## 5. 维护机制（防再次烂尾）

- **单一真相源**：新建 `docs/ROADMAP.md` 一页纸（当前尚不存在），只维护 Gate 进度和 DoD 勾选，不写长文
- Gate 3 内部允许拆轮次，Gate 间顺序不跳
- 上游同步：每月一次 cherry-pick 窗口，解析逻辑修复优先，UI 不动
- 决策记录：重要取舍写 commit message，不另开文档
- 旧编号（P/M 体系）彻底废弃，新任务一律挂 Gate 编号

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| CF 自动过盾失败或不可持续 | 时间盒管理，手动 cookie 流程永久保留为降级路径 |
| iOS 无付费账号限制分发 | 定位已明确为源码+侧载文档，不追 TestFlight |
| Gate 2 体量大导致节奏失控 | 每完成一个纵深方向即在 ROADMAP 可见进度；CF 攻坚独立时间盒不阻塞其余 |
| 单人+AI 长线作战疲劳 | 每道 Gate 都是独立冲刺，DoD 即休息点 |
