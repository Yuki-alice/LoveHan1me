git fsck --no-progress → EXIT=43

**根因已定位**（不是部分克隆）：
- `.git/config` 无 `partialclonefilter` / `promisor` → **不是 blobless 部分克隆**。

- `git multi-pack-index verify` → `failed to load pack in position 0 / 1 / 2`。

⇒ 典型"中断的 repack/gc 先删旧包、新包未写完"签名（与上一任看到的
`.git/objects/maintenance.lock`、`shallow.lock` 同一件事）。

**当前 git 可用性**：
- ✅ `git status --short`、`git rev-parse HEAD`、`git write-tree`（→ `8495959a`，退出 0）、`git ls-files`（1345 条）**可用** ⇒ **工作区与索引完好，提交大概率能成**。

- ⛔ `git stash` / `git gc` / `git repack` **禁用**（会读到缺失对象，可能造成二次损坏或误删）。
