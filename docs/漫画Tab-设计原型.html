直接复用 vs 需要新造

  • 复用：卡片（VideoCardItem 已支持 3:4 竖卡）、chip、顶栏、空/错/加载态、骨架屏、ContentColumn、分类矩阵、网格、LoadMoreFooter、Rail/底栏（遍历 MainTab.entries 自动加项）、转场动效。
  • 新造：①「继续阅读」卡片（首页没有横滑/续读先例）；② 阅读器（全屏沉浸页完全无先例）；③ 一级导航加「漫画」项（要新 icon + 文案，并接进全屏判定）。

需要你拍的三个决定

  • 导航顺序：现按「首页 / 漫画 / 发现 / 我的」排 —— 两个内容首屏相邻、搜索居中、我的收尾。也可以放「发现」之后。
  • 最新用无限滚动还是页码器：站点是 ?page=N 数字分页。原型按现有 LoadMoreFooter 走无限滚动。
  • 阅读器默认模式：原型默认连续纵向滚动。要不要把「单页」作为默认（更接近站点习惯）？
